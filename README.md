# 🎹 My Custom NohBoard Layout

A personalized keyboard layout for **NohBoard (Rewrite)**. Perfectly designed for streamers, content creators, or keyboard enthusiasts who want a clean, stylish way to display their keystrokes on screen.

Since I absolutely love this layout but couldn't find it online anymore, I am hosting it here so it never gets lost again!

## ✨ Features
* **Custom Design:** Optimized for maximum readability during live streams or video recordings.
* **Sleek & Compact:** Perfectly balanced key spacing and color palette.
* **Easy Integration:** Works flawlessly with OBS Studio, Streamlabs, and other broadcasting software.

## 🚀 Installation & Usage

Follow these simple steps to load the layout into your NohBoard client:

### 1. Download
* Download the files from this repository (either click the green **Code** button and select **Download ZIP**, or clone it via Git).

### 2. Add to NohBoard
1. Navigate to your local **NohBoard folder**.
2. Open the subfolder named `keyboards`.
3. Create a new folder inside it (e.g., `MyCustomLayout`) and paste the downloaded layout files (such as `.json`, `.definitions`, or image files) there.

### 3. Load the Layout
1. Launch `NohBoard.exe`.
2. **Right-click** anywhere on the NohBoard window and select **Load Keyboard**.
3. In the dropdown category menu, select the folder name you just created.
4. Click on your custom layout and hit **Close**.

## 🎥 OBS Studio Setup (Optional)

To display the layout with a transparent background in OBS:
1. Add a new **Window Capture** source in OBS and select the NohBoard window.
2. Right-click the source and go to **Filters**.
3. Add a **Chroma Key** (or *Color Key*) filter.
4. Set the key color type to match your NohBoard background color (usually bright green or blue) to make it completely transparent.
